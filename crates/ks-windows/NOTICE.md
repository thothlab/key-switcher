# NOTICE — ks-windows

Код крейта написан для KeySwitcher; дословно заимствованного кода нет.

## Тестовая фикстура `tests/fixtures/kbdru.klc`

- **Что:** таблица раскладки Windows «Русская» (KBDRU) в формате KLC — разделы заголовка,
  `SHIFTSTATE` и `LAYOUT`. Остальные разделы опущены, файл переведён из UTF-16 в UTF-8, в начало
  добавлены две строки комментария об источнике.
- **Источник:** <https://kbdlayout.info/kbdru/download/klc> (скачан 2026-10-12). kbdlayout.info
  генерирует этот файл из `KBDTABLES` в `kbdru.dll` версии 10.0.29667.1000. Сама раскладка
  принадлежит Microsoft: «© Microsoft Corporation. All rights reserved.», как сказано в файле.
- **Как используется:** только как тестовая фикстура. `tests/seams.rs` сверяет с ней коды клавиш,
  построение таблицы раскладки и фикстуру `ks-core/tests/fixtures/ru_win.tsv`. В бинарник
  `keyswitcher` файл не попадает: в продукте таблицы раскладок строятся на ходу через
  `ToUnicodeEx` из раскладок, установленных у пользователя.
