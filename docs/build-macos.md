# KeySwitcher на macOS: сборка, подпись, права

KeySwitcher — агент в строке меню (без иконки в Dock). Bundle ID — `com.keyswitcher.app`, бинарник — `KeySwitcher.app/Contents/MacOS/keyswitcher`. Требуется macOS 13+, Rust из `rustup`.

## 1. Один раз: локальный сертификат подписи

Права macOS (TCC) привязаны к подписи приложения. Подпись ad-hoc меняется с каждой сборкой, и права после пересборки молча перестают действовать. Стабильная локальная подпись этого избегает:

```sh
scripts/macos/create-local-cert.sh          # создаёт «KeySwitcher Local» в связке ключей «вход»
security find-identity -p codesigning       # в списке должен быть "KeySwitcher Local"
```

Вручную то же: «Связка ключей» → меню «Ассистент сертификации» → «Создать сертификат…», имя `KeySwitcher Local`, тип идентичности «Самоподписанный корневой», тип сертификата «Подпись кода».

## 2. Сборка

```sh
KS_SIGN_IDENTITY="KeySwitcher Local" scripts/macos/build-app.sh   # стабильная подпись
scripts/macos/build-app.sh                                         # ad-hoc, с предупреждением
KS_UNIVERSAL=1 KS_SIGN_IDENTITY="KeySwitcher Local" scripts/macos/build-app.sh   # arm64 + x86_64
codesign -dv dist/KeySwitcher.app                                  # кем подписано
```

Результат — `dist/KeySwitcher.app`. Сети сборка не требует: словари встроены в бинарник.

## 3. Установка

```sh
mkdir -p ~/Applications
ditto dist/KeySwitcher.app ~/Applications/KeySwitcher.app
open ~/Applications/KeySwitcher.app
```

## 4. Права: «Мониторинг ввода» и «Универсальный доступ»

При первом запуске macOS спросит оба права. Если окна не было или права отклонены:

1. «Системные настройки» → «Конфиденциальность и безопасность» → «Мониторинг ввода» — включить KeySwitcher (кнопка «+», если его нет в списке). Нужно, чтобы видеть нажатия и распознать слово в не той раскладке.
2. Там же → «Универсальный доступ» — включить KeySwitcher. Нужно, чтобы стереть слово, напечатать исправленное и придержать клавишу на время замены.
3. Перезапустить KeySwitcher: права действуют только на новый процесс. Кнопка «Перезапустить KeySwitcher» в разделе «Разрешения» окна настроек делает это сама (или меню иконки → «Выход», затем снова открыть).

Если при запуске какого-то права нет, агент сам открывает окно настроек на разделе «Разрешения»: там статус каждого права, зачем оно нужно, кнопка «Открыть системные настройки» (ведёт прямо в нужный раздел через `x-apple.systempreferences:com.apple.preference.security?Privacy_ListenEvent` и `?Privacy_Accessibility`) и «Перезапустить KeySwitcher». Перезапуск: агент получает по сокету команду `restart`, запускает отвязанный `sh`, который ждёт выхода агента (не дольше 10 с) и делает `open` бандла, и выходит. Раздел показывает права процесса окна: окно, открытое из меню агента, видит права KeySwitcher.app; окно, запущенное из Терминала командой `--settings`, — права Терминала.

**Почему в `Info.plist` нет описаний использования.** У «Мониторинга ввода» и «Универсального доступа» ключей `NS…UsageDescription` нет вовсе: macOS не показывает для них текст приложения, а объяснение даёт само окно настроек (раздел «Разрешения»). `NSAppleEventsUsageDescription` не нужен: KeySwitcher не шлёт Apple Events — TextEdit для `--selftest` и бандл при перезапуске открываются через `open` (LaunchServices), текст поля читается через «Универсальный доступ». Других защищённых ресурсов (камера, микрофон, контакты, файлы пользователя) KeySwitcher не трогает.

Без права «Универсальный доступ» KeySwitcher ничего не стирает и не глотает: исправление просто не происходит, подсказка иконки — «KeySwitcher — нужны разрешения».

## 5. Проверка

```sh
~/Applications/KeySwitcher.app/Contents/MacOS/keyswitcher --status
~/Applications/KeySwitcher.app/Contents/MacOS/keyswitcher --selftest
```

- `--status` спрашивает работающий агент через сокет `~/Library/Application Support/KeySwitcher/agent.sock` и печатает его состояние: «клавиатура отслеживается», права, «безопасный ввод: нет», приложение в фокусе (как его видит агент), найденные раскладки, состояние автоисправления или ошибку файла настроек. Если агент не запущен, команда пишет об этом и показывает права процесса, из которого её запустили (Терминала), а не KeySwitcher.app.
- `--selftest` запускает агент через `open`, если он не запущен, и просит его прогнать сценарии: агент открывает новый документ TextEdit, печатает сценарии, читает текст поля через «Универсальный доступ» и печатает `PASS`/`FAIL` по каждому. Код выхода 0 — все прошли. На время проверки не трогайте клавиатуру и мышь. Проверка трогает только собственный документ `KeySwitcher-selftest.txt` во временном каталоге: если в фокусе другое окно или поле, она останавливается, ничего не стирая. При `FAIL` печатаются ожидаемая строка, длина фактического текста и позиция первого расхождения, но не сам текст. Сценарии лежат в `crates/ks-app/selftest/*.toml` (по файлу на задачу); среди них отмена ⇧⇧, ручная конвертация ⇧⇧ и конвертация выделения ⌥⇧. Сценарий выделения кладёт в буфер обмена своё значение и проверяет, что после операции буфер вернулся к нему; ваш буфер обмена сохраняется до такого сценария и возвращается после.
- В `--status` также видны сбои исполнителя замены (паника или зависание дольше 1,5 с — клавиатура при этом отпускается, удержанные нажатия сбрасываются) и отказы переключения раскладки при замене.

## Окно настроек и автозапуск

- **Окно настроек** — меню иконки → «Настройки…» или `keyswitcher --settings [--section general|hotkeys|apps|words|permissions|about]`. Отдельный процесс; второй вызов не открывает второе окно, а поднимает первое на нужном разделе. Окно пишет только `config.toml`, агент применяет правку сам, без перезапуска.
- **Автозапуск** включён по умолчанию (`autostart = true`). Агент при старте и после каждой правки файла настроек ставит или убирает запись `~/Library/LaunchAgents/com.keyswitcher.app.plist`: `launchd` при входе в систему запускает `KeySwitcher.app/Contents/MacOS/keyswitcher` (`RunAtLoad`, без `KeepAlive` — «Выход» не перезапускает агент). Запись указывает на тот бандл, из которого агент запущен: перенесли `.app` — запустите его один раз, запись обновится. При первой записи macOS показывает уведомление «Добавлены фоновые объекты». Выключить — флажок в «Общих» окна настроек или `autostart = false`; запись удаляется. Агент, запущенный не из `.app` (`cargo run`), запись не трогает.

## 6. «Права слетели после пересборки»

Симптом: переключатели KeySwitcher в «Мониторинге ввода» и «Универсальном доступе» включены, но `--status` пишет «НЕ выдано» или «клавиатура не отслеживается», исправления не происходят, системного окна с вопросом нет. Причина — новая сборка подписана иначе (обычно ad-hoc), и старая запись TCC к ней не относится.

Лечение:

1. Собрать со стабильной подписью (`KS_SIGN_IDENTITY="KeySwitcher Local"`), чтобы это не повторялось.
2. Удалить KeySwitcher из обоих списков кнопкой «−» (или `tccutil reset Accessibility com.keyswitcher.app` и `tccutil reset ListenEvent com.keyswitcher.app`).
3. Запустить KeySwitcher, выдать права заново, перезапустить его.

## 7. Иконка и меню

Иконка в строке меню показывает состояние, подсказка при наведении — «KeySwitcher — …»:

| Состояние | Когда |
|---|---|
| работает | права есть, пара раскладок RU + EN найдена, автоисправление включено |
| автоисправление выключено | снята отметка «Автоисправление» в меню или нажаты оба Shift вместе |
| пауза: безопасный ввод | другое приложение держит Secure Input (поле пароля, менеджер паролей) |
| нужны разрешения | нет «Мониторинга ввода» или «Универсального доступа» |
| Нужны раскладки RU и EN | в системе не включены русская и английская раскладки |
| ошибка в файле настроек | `config.toml` не разбирается — см. раздел 9 |

Меню: строка состояния; «Автоисправление» (отметка); «Не исправлять в <приложение>» для приложения, которое было в фокусе перед открытием меню, или «Исправлять в <приложение>», если оно уже исключено; «Не исправлять „<слово>“» — только после отмены исправления двойным Shift и до следующего исправления; «Настройки…» (окно появится позже); «Выход». Пункты меню сразу записываются в `config.toml`.

## 8. Где KeySwitcher молчит сам

- **Приложения-исключения.** Встроенный список: терминалы, среды разработки, менеджеры паролей (Terminal, iTerm2, Xcode, «Пароли», 1Password и др.). В них автоисправление выключено, пока вы не выберете в меню «Исправлять в …» — приложение попадёт в `[apps] enabled`. Любое другое приложение выключается пунктом «Не исправлять в …» (`[apps] disabled`).
- **Безопасный ввод.** Пока macOS держит Secure Input (фокус в поле пароля), KeySwitcher ничего не обрабатывает, иконка показывает паузу. Состояние перечитывается раз в секунду; когда поле пароля теряет фокус, работа возобновляется сама. Если пауза не проходит, Secure Input держит какое-то приложение в фоне — это видно в `--status` («безопасный ввод: да»).

## 9. Конвертация выделения и файл настроек

- **Выделение.** Выделите текст и нажмите ⌥⇧ (Option, затем Shift, отпустить). KeySwitcher копирует выделение через буфер обмена, конвертирует в другую раскладку пары (латинских букв больше — в русскую, иначе в английскую), вставляет и примерно через четверть секунды возвращает буфер обмена, который был до операции (все типы содержимого). Пустое выделение — ничего не меняется. В Terminal и iTerm2 выделение не трогается: вставка там не заменяет выделенное. Знаки конвертируются по включённой раскладке: в «Русской» (Apple) `?` остаётся `?`, а `&` становится `.`; в «Русская – ПК» — `,` и `?`.
- **Файл настроек** — `~/Library/Application Support/KeySwitcher/config.toml`, создаётся при первом запуске. Правка применяется сразу, без перезапуска. Неизвестные ключи пропускаются с предупреждением в журнале (только имя ключа). Если файл не разбирается, KeySwitcher работает на значениях по умолчанию, в меню и `--status` — номер строки и имя ключа (без значений), а сам файл не перезаписывается, пока вы его не исправите; пункты меню до этого действуют только в памяти, до следующего перечитывания файла.
- **Приватность.** Сетевых запросов нет. Набранный текст не пишется ни на диск, ни в журнал: на диске только `config.toml` (список «никогда» пополняется лишь пунктом меню «Не исправлять „…“» или вручную), сокет `agent.sock` и документ проверки `KeySwitcher-selftest.txt` во временном каталоге.
